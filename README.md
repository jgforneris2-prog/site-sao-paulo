# Tricolor Paulista

Site de estudo sobre o São Paulo Futebol Clube feito com HTML, CSS e JavaScript.

## Requisitos do exercício
- 15 páginas únicas (`*.html`)
- 3 níveis de CSS: externo (`css/style.css`), interno (`<style>` em cada página) e inline (atributos `style`)
- Seletores de classe, id e tag em todos os níveis
- Pelo menos 1 ação de JavaScript por página (`js/`)
- 3 APIs em 3 páginas separadas:
  - `historia.html`: API REST da Wikipédia
  - `estadio.html`: ViaCEP
  - `clima.html`: Open-Meteo

## Como abrir
Abra `index.html` no navegador (as APIs precisam de internet).
